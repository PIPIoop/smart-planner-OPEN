## Покрытые сценарии

Python проверяет общий Dart JSON-контракт, CRUD, атомарную замену, идемпотентное создание, CORS, health/schemaVersion, Telegram mapping, сетевую ошибку, относительное время «через два часа», поиск накладок, свободные окна, рекомендации и owner guard, числовые и словесные диапазоны времени, отказ от обратного диапазона и передачу 120 минут в API.

Flutter проверяет расписание цели через день, обязательный период, меньший вес позднего выполнения, сохранение пропуска после удаления, атомарное создание цели, доменную валидацию длительности с шагом 15 минут, JSON round-trip, ViewModel lifecycle/rollback, внешнюю синхронизацию и защиту от устаревшего GET, HTTP endpoints и UTF-8, desktop/mobile UI, создание после валидации, выбор двухчасовой длительности в форме и все шесть шагов обучения.

Microsoft Edge проверяет создание цветной группы через UI, появление группированной задачи без refresh, безопасное снятие группы при удалении, создание цели и 16 связанных задач, полное имя шаблона, обновление своевременного прогресса, сворачивание панели, внешнее создание и удаление 90-минутной задачи без refresh с отображением диапазона 10:00–11:30, реальную загрузку из API, обучение, отказ при пустом названии, создание двухчасовой задачи через веб-форму, отображение 09:00–11:00, сохранение после refresh, выполнение, поиск, подтверждение удаления и компоновку 480×900. Снимки находятся в `test_artifacts/shared_edge`.
