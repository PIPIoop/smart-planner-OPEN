# Smart Planner — методичка по ролям, подпискам и копейкам

## 1. Денежные суммы с копейками

Во всех формах финансов теперь можно вводить копейки.

Корректные примеры:

```text
450
450,5
450,50
450.50
1 250,75
```

Все они сохраняются точно. Например `1 250,75 ₽` хранится как `125075` копеек.

Если введено больше двух цифр после запятой (`1250,755`), операция не создаётся и интерфейс сообщает, что сумма некорректна.

Целые суммы отображаются компактно (`1 250 ₽`), суммы с копейками — `1 250,75 ₽`.

## 2. Роли

### User

Это роль любого обычного пользователя. Она назначается автоматически.

### Admin

Роль администратора назначается только на сервере. В приложении нет кнопки «сделать себя администратором».

Администратор:

- видит пользователей;
- может открыть их календарь и финансы;
- не может менять чужие задачи и деньги;
- управляет только аккаунтом/подпиской/trial/временными допами.

При просмотре чужих данных сверху отображается жёлтый блок **«Режим администратора · только просмотр»**.

## 3. Тарифы

### Free

Для базового планирования:

- календарь и обычные задачи;
- до 3 групп;
- до 2 целей;
- базовый Telegram;
- 20 AI-действий в месяц;
- 10 голосовых сообщений в месяц;
- базовый отчёт;
- аналитика до 30 дней.

### Plus

Всё Free плюс:

- несколько задач из одного сообщения;
- умный поиск свободного времени;
- расширенный Telegram-секретарь;
- расширенные отчёты;
- аналитика до года;
- AI и голос визуально безлимитны.

Финансы в Plus недоступны для записи.

### Full

Всё Plus плюс полный финансовый центр:

- счета;
- расходы/доходы/переводы;
- категории;
- финансовые цели;
- платежи;
- долги;
- финансовая аналитика;
- финансовые команды Telegram;
- будущие банковские возможности.

## 4. Trial

Новый пользователь получает 14 дней Full.

После окончания trial аккаунт автоматически становится Free. Никакие данные не удаляются.

Администратор может выдать trial повторно и указать любое число дней в разрешённом диапазоне.

## 5. Если закончился Full

Счета, история операций, цели, платежи и долги сохраняются.

Пользователь может их просматривать, но не может создавать/изменять/удалять финансовые данные.

Telegram-команды просмотра также остаются рабочими:

```text
Сколько осталось денег?
Сколько я потратил в этом месяце?
На что больше всего трачу?
```

Команда создания расхода будет заблокирована до возврата Full или временного допа.

## 6. Admin-панель

После административного web-входа в верхней навигации появился раздел **«Админ»**.

### Выбор пользователя

В выпадающем списке доступны обычные пользователи реестра. Admin-панель также может показывать pending/blocked/deactivated пользователей для управления их подпиской.

Для активного пользователя выбор синхронизируется с календарём. Если затем нажать «Календарь» или «Финансы», откроются его данные в read-only режиме.

### Изменить тариф

Нажмите:

`Изменить тариф` → `Free / Plus / Full` → `Ручная выдача / Месяц / Год` → при необходимости дата окончания → `Сохранить`.

Изменение попадает в audit log, пользователю создаётся уведомление.

### Сбросить подписку

`Сбросить на Free` не удаляет историю подписки и пользовательские данные.

Он только завершает платный доступ и переводит аккаунт в Free.

### Выдать trial

`Выдать trial` → укажите число дней → `Выдать`.

Пользователь получает Full на этот срок.

### Выдать временный доп

`Выдать доп` → выберите тип.

#### Доступ

Можно временно открыть:

- Финансы;
- Финансы в Telegram;
- Умное планирование;
- Несколько задач в сообщении;
- Расширенные отчёты.

#### Бонус лимита

Можно добавить:

- AI-действия;
- голосовые сообщения;
- группы;
- цели.

Укажите срок действия в днях и, желательно, причину.

Доп автоматически прекратит действие в заданную дату. Пользователь будет уведомлён.

### Отозвать доп раньше срока

В блоке «Временные допы» нажмите крестик справа от нужного допа.

Событие попадёт в audit log, пользователь получит уведомление.

## 7. Audit history

Внизу admin-страницы расположен блок **«История изменений»**.

Он показывает административные и системные события, в том числе:

- смену тарифа;
- выдачу trial;
- reset Free;
- выдачу/отзыв допа;
- автоматическое окончание trial/подписки/допа.

## 8. Grace period

Статус `past_due` предназначен для будущей платёжной системы.

После проблемы с оплатой сохраняется 3 дня доступа. Если оплата не восстановлена, система переводит пользователя на Free и сохраняет данные.

## 9. Telegram и подписки

### Free

Можно создавать обычные одиночные задачи. При попытке использовать платную функцию бот объяснит, что она доступна в Plus/Full.

### Plus

Доступны:

- multi-task;
- умный подбор времени;
- расширенные отчёты;
- увеличенные технические AI/voice лимиты.

### Full

Дополнительно разрешена запись финансовых операций:

```text
Потратил 1250,75 рублей на продукты
Получил 85000,50 рублей
Перевёл 10000,25 на накопительный
```

Перед записью бот по-прежнему просит подтверждение.

## 10. Уведомления о подписке

Когда администратор:

- меняет тариф;
- выдаёт trial;
- выдаёт доп;
- отзывает доп;

или когда подписка/доп заканчивается автоматически, создаётся уведомление.

Telegram доставит его при следующем взаимодействии пользователя с ботом.

## 11. Локальная проверка после обновления

Из корня Flutter-проекта:

```bash
flutter clean
flutter pub get
flutter analyze
flutter test
flutter run -d edge
```

Python:

```bash
python -m pytest services/task_api/tests -q
python -m pytest services/tg_voice_bot/tests -q
```

Если Telegram-тестам в вашей среде нужны зависимости, запускайте их из того же Python/venv, в котором запускается бот.

## 12. Что важно не делать

- не хранить деньги в `double`;
- не добавлять клиентский endpoint для смены роли;
- не проверять тариф только во Flutter — server-side gates обязательны;
- не удалять финансовые данные при downgrade;
- не превращать временный доп в новый тариф;
- не удалять audit history при reset подписки.
