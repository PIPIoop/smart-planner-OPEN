# Методичка по использованию Telegram-секретаря Smart Planner

## 1. Что умеет текущая версия

Секретарю можно писать или отправлять голосовые сообщения. Он умеет:

- создать одну задачу;
- найти несколько задач в одном сообщении;
- распознать дату и точное/ориентировочное время;
- распознать длительность;
- распознать приоритет;
- распознать дедлайн;
- оставить задачу без конкретного времени;
- подобрать до трёх свободных окон;
- предупредить о конфликте;
- не записывать новую временную задачу поверх существующей;
- последовательно подтвердить, изменить или пропустить каждую найденную задачу.

Все задачи попадают во **внутренний календарь Smart Planner**. Google Calendar в этой версии не используется.

## 2. Быстрый запуск

В обычной рабочей копии проекта откройте три PowerShell-терминала в корне.

### Терминал 1 — Task API

```powershell
.\run_task_api.ps1
```

### Терминал 2 — Flutter Web

```powershell
.\run_web_with_api.ps1
```

### Терминал 3 — Telegram-бот

```powershell
cd .\services\tg_voice_bot
.\venv\Scripts\python.exe .\bot.py
```

Файл `services/tg_voice_bot/.env` должен быть заполнен по `.env.example`. Не публикуйте `.env` и реальные токены.

Если виртуальное окружение создаётся заново:

```powershell
py -3.10 -m venv .\services\tg_voice_bot\venv
.\services\tg_voice_bot\venv\Scripts\python.exe -m pip install -U pip
.\services\tg_voice_bot\venv\Scripts\python.exe -m pip install -r .\services\tg_voice_bot\requirements.txt
```

## 3. Одна задача с точным временем

Напишите:

```text
Завтра в 15:00 встреча с Иваном
```

Бот покажет распознанную задачу.

Если длительность не указана, после подтверждения появится выбор:

```text
30 мин | 1 час | 2 часа
Своя длительность
```

После выбора длительности секретарь проверит внутренний календарь.

Если 15:00 свободно — задача будет сохранена.

Если время занято — бот не создаст пересечение и предложит свободные варианты.

## 4. Задача с уже указанной длительностью

```text
Завтра в 15:00 встреча с Иваном на 1 час 30 минут
```

или:

```text
Завтра в 15 часов встреча на два часа
```

Дополнительный вопрос о длительности не нужен.

## 5. Гибкая задача: пусть секретарь выберет время

```text
Завтра 2 часа поработать над проектом
```

У задачи есть дата и длительность, но нет точного старта.

После подтверждения бот прочитает календарь и покажет до трёх свободных вариантов, например:

```text
09.08 · 08:00–10:00
09.08 · 13:00–15:00
09.08 · 19:00–21:00
```

Нажмите нужное окно.

## 6. Ориентир «утром / днём / вечером / ночью»

```text
Завтра вечером час английского
```

`вечером` считается ориентиром, а не жёстко зафиксированным временем. Секретарь старается предложить варианты ближе к вечернему периоду, соблюдая занятость и дедлайн.

## 7. Задача без времени

```text
Завтра купить продукты
```

Если задача не должна занимать конкретный блок календаря:

1. подтвердите распознавание;
2. выберите **«Оставить без времени»**.

Такая задача будет привязана к дате, но не будет мешать подбору свободных временных окон.

## 8. Несколько задач одним сообщением

Пример:

```text
Завтра в 10 стоматолог, после него заехать в магазин,
вечером час английского и не забыть отправить отчёт до 18
```

Бот ответит:

```text
Найдено задач: 4
```

Затем задачи обрабатываются одна за другой:

```text
Задача 1 из 4
[Подтвердить] [Изменить] [Пропустить]

        ↓

Задача 2 из 4
[Подтвердить] [Изменить] [Пропустить]

        ↓
       ...
```

После последней задачи бот покажет итоговое количество сохранённых и пропущенных элементов.

### Как лучше диктовать список

Для высокой точности используйте короткие независимые формулировки:

```text
Завтра в 10 стоматолог, потом купить продукты, затем позвонить маме
```

или:

```text
Завтра:
подготовить отчёт;
позвонить Ивану;
вечером час английского
```

## 9. Редактирование найденной задачи

Нажмите **«Изменить»**.

После этого пришлите **текущую задачу целиком** с исправленными данными.

Например, было:

```text
Завтра встреча с Иваном
```

Нажали «Изменить» и отправили:

```text
Послезавтра в 16:30 встреча с Иваном на 90 минут
```

Во время редактирования одного элемента списка не присылайте сразу новый список задач — бот ожидает одну исправленную текущую задачу.

## 10. Приоритет

Можно говорить естественно.

### Высокий

```text
Срочно отправить договор завтра
Обязательно позвонить врачу в пятницу
Важно закончить презентацию завтра
```

### Обычный

Без специального маркера.

### Низкий

```text
Если успею завтра почитать книгу
По возможности разобрать документы в субботу
Не срочно купить новый кабель
```

## 11. Дедлайн

Примеры:

```text
Отправить отчёт до пятницы
Срочно отправить отчёт до пятницы до 18:00
Подготовить документы к 10 августа
```

Если задача имеет дедлайн и длительность, но не имеет точного времени, секретарь ищет подходящий блок до дедлайна.

Например:

```text
До пятницы подготовить презентацию, нужно 2 часа
```

может быть размещено раньше пятницы, если там есть подходящее свободное окно.

## 12. Что происходит при конфликте

Предположим, в календаре уже есть:

```text
15:00–16:30 Тренировка
```

Вы отправили:

```text
Завтра в 15:30 встреча на час
```

Секретарь:

1. обнаружит пересечение;
2. не сохранит новую встречу поверх тренировки;
3. покажет свободные альтернативы;
4. сохранит только выбранное пользователем окно.

Существующая тренировка автоматически не переносится.

## 13. Почему календарь проверяется ещё раз после выбора

Между показом кнопки и нажатием пользователя в календаре может появиться другое событие.

Поэтому непосредственно перед записью выполняется повторная проверка. Если окно уже заняли, секретарь предложит обновлённые варианты.

Это штатное поведение, а не ошибка.

## 14. Если Task API временно недоступен

Для временных задач секретарь не будет считать календарь пустым.

Вы увидите сообщение о невозможности безопасно проверить или подобрать окно.

После восстановления Task API повторите подтверждение либо сохраните задачу без времени, если это соответствует её смыслу.

## 15. Команды секретаря

| Команда | Назначение |
|---|---|
| `/start` | краткое знакомство с новым сценарием |
| `/help` | примеры формулировок |
| `/menu` | меню секретаря |
| `/today` | задачи на сегодня |
| `/week` | обзор недели |
| `/tasks` | список задач |
| `/free` | существующий обзор свободных окон |
| `/settings` | настройки существующего секретаря |
| `/report` | отчёт за неделю или месяц |

## 16. Рекомендации по формулировкам

Лучше:

```text
Завтра в 14:30 созвон с командой на 45 минут
```

чем:

```text
Надо бы как-нибудь завтра ближе к середине дня созвониться со всеми ненадолго
```

Лучше:

```text
До пятницы срочно подготовить отчёт, нужно 2 часа
```

чем длинная фраза с несколькими вложенными условиями.

Текущий распознаватель детерминированный: он специально сделан предсказуемым и не отправляет текст во внешний LLM.

## 17. Текущие ограничения

Сейчас отсутствуют:

- Google Calendar;
- повторяющиеся задачи;
- автоматический перенос существующих событий;
- персональное обучение привычкам;
- пользовательские часы сна/работы для автопланирования;
- отдельная форма дедлайна в Flutter;
- восстановление незавершённой очереди подтверждений после рестарта бота.

Черновики Telegram-подтверждений хранятся временно. Если долго не нажимать кнопку или перезапустить бот, задачу потребуется отправить заново.

## 18. Быстрый набор примеров для проверки после запуска

```text
Завтра купить хлеб и молоко
```

```text
Завтра 2 часа поработать над проектом
```

```text
Завтра вечером полтора часа тренировка
```

```text
Срочно отправить отчёт до пятницы до 18:00
```

```text
Завтра в 10 стоматолог, после него заехать в магазин, вечером час английского и не забыть отправить отчёт до 18
```

Последний пример должен показать `Найдено задач: 4` и запустить последовательную обработку.
